# 채널 Up/Down 기능 구현 보고서

## 1. 작업 개요

- 작업 대상: TV 리모컨 채널 up/down 입력 처리
- 적용 범위: `remoteKey`, `TVController`, `TVControllerTest`
- 핵심 제약: 기존 구조체 및 컨트롤러 상태 필드 추가 없이 구현
- 검증 기준: `cmake --build build` 및 `ctest --test-dir build` Green

## 2. 요구사항 반영 내용

| 구분 | 요구사항 | 반영 결과 |
| --- | --- | --- |
| 채널 up | 현재 채널에서 `+1` | `KEY_CH_UP` 입력 시 현재 채널 번호를 읽어 1 증가 |
| 채널 down | 현재 채널에서 `-1` | `KEY_CH_DOWN` 입력 시 현재 채널 번호를 읽어 1 감소 |
| 두 자리 초과 | 채널은 두 자리수를 넘을 수 없으며 초과 시 1번 | `99`에서 up 시 `1`로 변경 |
| 음수 방지 | 채널은 음수일 수 없으며 `0`에서 down 시 99번 | `0`에서 down 시 `99`로 변경 |
| 구조 제약 | 구조체 수정 없이 구현 | 기존 클래스 멤버 추가 없이 익명 namespace helper로 처리 |

## 3. 변경 파일

### `include/remoteKey.h`

- `remoteKey` enum에 채널 이동 키 추가
  - `KEY_CH_UP`
  - `KEY_CH_DOWN`

### `src/remoteKey.cpp`

- 새 키의 문자열 변환 추가
  - `KEY_CH_UP` -> `"CH_UP"`
  - `KEY_CH_DOWN` -> `"CH_DOWN"`

### `src/TVController.cpp`

- 현재 채널과 이동 방향을 받아 다음 채널을 계산하는 파일 내부 helper 추가
- `dispatchNonDigitKey()`에 `KEY_CH_UP`, `KEY_CH_DOWN` 분기 추가
- 컨트롤러의 새 상태 필드 없이 `tuner->getCurrentCH()` 결과를 기준으로 동작

### `test/TVControllerTest.cpp`

- 채널 up 일반 케이스 추가: `6 -> 7`
- 채널 down 일반 케이스 추가: `6 -> 5`
- 채널 up 상한 경계 케이스 추가: `99 -> 1`
- 채널 down 하한 경계 케이스 추가: `0 -> 99`

## 4. 테스트 결과

실행 명령:

```powershell
cmake --build build; if ($LASTEXITCODE -eq 0) { ctest --test-dir build }
```

결과:

- 전체 테스트: 40개
- 성공: 40개
- 실패: 0개
- 최종 상태: Green

## 5. 참고 사항

- Windows PowerShell 환경에서 `&&`가 지원되지 않아 동일 의미의 조건 실행문으로 빌드 후 테스트를 수행했다.
- 커버리지 설정이 활성화된 빌드 디렉터리에서 테스트를 실행하여 `build/` 하위 산출물 및 `.gcda` 파일들이 함께 갱신되었다.
