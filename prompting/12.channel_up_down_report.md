### Assistant 검증

처음 사용자 요청의 명령인 `cmake --build build && ctest --test-dir build`를 실행하려 했으나, 현재 PowerShell 환경에서 `&&`가 statement separator로 지원되지 않아 파서 오류가 발생했다.

동일 의미로 다음 명령을 실행했다.

```powershell
cmake --build build; if ($LASTEXITCODE -eq 0) { ctest --test-dir build }
```

- 성공: 40개
- 실패: 0개
- 최종 상태: Green

- 빌드 및 테스트 실행으로 `build/` 하위 산출물과 coverage 파일들이 갱신되었다.
- IDE linter는 include path를 찾지 못하는 기존 환경성 진단을 표시했지만, 실제 CMake 빌드와 CTest는 정상 통과했다.
