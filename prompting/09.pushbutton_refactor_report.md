## 4. 구현 Transcript

### 4.1 기준선 검증

Assistant는 먼저 기준선 테스트를 실행하려 했다.

```powershell
cmake --build build && ctest --test-dir build --output-on-failure
```

PowerShell 환경에서 `&&`가 지원되지 않아 다음 오류가 발생했다.

```text
The token '&&' is not a valid statement separator in this version.
```

Assistant는 PowerShell 문법에 맞게 명령을 변경해 기준선을 재검증했다.

```powershell
cmake --build build; if ($LASTEXITCODE -eq 0) { ctest --test-dir build --output-on-failure }
```

```text
100% tests passed, 0 tests failed out of 36
```

### 4.3 `FavoriteChannels` 타입 추가

Assistant는 즐겨찾기 정책을 다음 타입으로 분리했다.

```cpp
class FavoriteChannels {
public:
  void toggle(int channel);
  std::optional<int> nextAfter(int current) const;
  bool empty() const;
  std::vector<int> values() const;

private:
  std::vector<int> channels_;
};
```

구현 책임:

- `toggle(int channel)`: 기존 채널이면 제거, 없으면 추가 후 정렬
- `nextAfter(int current)`: 다음 큰 즐겨찾기 또는 첫 즐겨찾기 반환
- `values() const`: 기존 `getFavorites()` 호환을 위한 값 반환

### 4.4 `TVController` helper 추출

Assistant는 `TVController`에 다음 private helper를 추가했다.

- `isDigitKey(remoteKey key)`
- `digitString(remoteKey key)`
- `setTunerChannel(const std::string& channel)`
- `clearProcessingChannel()`
- `appendDigit(remoteKey key)`
- `commitProcessingChannel()`
- `toggleFavoriteChannel()`
- `moveToNextFavoriteChannel()`
- `currentChannelNumber() const`
- `dispatchNonDigitKey(remoteKey key)`

매직 넘버는 다음 상수로 분리했다.

```cpp
namespace {
constexpr std::size_t MaxAutoCommitChannelDigits = 2;
}
```

최종 `pushButton()`은 다음 형태가 되었다.

```cpp
void TVController::pushButton(remoteKey key) {
  if (isDigitKey(key)) {
    appendDigit(key);
    return;
  }
  dispatchNonDigitKey(key);
}
```
